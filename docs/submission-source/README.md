# Hackathon submission source

These XML fragments are source material for the CodeJam Track #5 hackathon
brief, not application runtime configuration. `hackathon-v2-skeleton.xml`
defines the document structure and the numbered `hackathon-v2-section-*.xml`
files contain its corresponding sections.

Keep the files together when regenerating or editing the hackathon submission.
They are retained for traceability and should not be consumed by the AgentRelay
application or deployment tooling.
